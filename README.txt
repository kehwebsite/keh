KARA EMBROIDERY HOUSE - WEBSITE
================================

WHAT THIS IS
Your complete website. index.html is the site; assets/ holds images
and the hero video; support.js makes the page run. Keep them together.

HOW TO PUT IT ONLINE (free, ~10 minutes)
1. Go to https://app.netlify.com/drop  (or Vercel / Cloudflare Pages)
2. Drag this whole folder onto the page
3. You get a live URL with HTTPS immediately
4. Connect your domain www.karaembroideryhouse.com in the site settings
   (Netlify shows you exactly which DNS records to set at your domain
   registrar)

EDITING LATER
- All text can be edited in index.html with any text editor
  (Notepad works). Search for the wording you want to change.
- Phone number appears as 918860850800 (WhatsApp links) and
  +918860850800 (call link). Search-replace to change it.
- To swap a product photo, replace the file in assets/ keeping the
  same filename.
- To compress the hero video (recommended, it is 3.25 MB):
  upload assets/hero-loop.mp4 to https://www.freeconvert.com/video-compressor
  aim for ~1 MB, save over the old file.
